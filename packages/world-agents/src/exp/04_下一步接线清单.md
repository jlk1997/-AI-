## 3. 插入 ReflectionGate → `maybeReflect`（核心）

| # | 文件 | 函数 | 插入位置与内容 |
|---|---|---|---|
| 3.1 | `reflect.ts` | `maybeReflect` | 在 **importance sum ≥ threshold** 之后、**LLM 生成 insight / `createMemoryEntry(kind:'reflection')` 之前** |
| 3.2 | 同上 | 证据集 | 将本轮 `evidence`（retrieveMemories + priors）作为 `candidateEvidence` |
| 3.3 | 同上 | Gate 调用 | 若 `shouldEvaluateGate(flags)`：`await gate.evaluate({ agentId, agentName, nowSimTime, stream, candidateEvidence, trackedFactKeys, trustedAnchors, minIndependentSources })` |
| 3.4 | 同上 | block 分支 | `if (!gateResult.allowUpgrade)` → 打 `reflect_attempt` 日志（`gate_decision:'block'`）→ **return**（A1 形状：空 reflections / null；与现有 `ReflectResult \| null` 对齐） |
| 3.5 | 同上 | pass 分支 | 继续现有 LLM / heuristic；写入时附 `gateDecision:'pass'`、`taintStatus:'clean'`（若类型已扩） |
| 3.6 | `reflect.ts` | `forceSeedReflections` | 若 `flags.forceSeedRespectsGate`：强制种子仍走 Gate；A0 跳过整条 reflect |

**推荐 import**：`createDefaultGate` / `MultiSourceContradictionGate` from scaffold `gate.ts`。

**trustedAnchors**：stream 中带 `correctionFactKey` 的观察，或系统真值条目。

## 5. 纠正运动 + TaintedReflectionRollback

| # | 文件 | 函数 / 位置 | 插入内容 |
|---|---|---|---|
| 5.1 | 纠正运动驱动（新小模块或 harness） | `t_correct` tick | 对每个目标 agent（或 Believe=1 子集）：若 `shouldRunRollback(flags)` → `rollback.runAtCorrection({...})` |
| 5.2 | 同上 | `reReflectHook` | **必须接线**：`async (rr) => maybeReflect({ stream: filteredView(rr), agentId, agentName, nowSimTime, sinceSimTime, threshold: 0 或 flags.reflectThreshold, idFactory, llm })`，且证据集已 `filterForRetrieval` |
| 5.3 | 同上 | 日志 | 写 `rollback_event` JSONL（见协议 §6.4） |
| 5.4 | A0/A1 | `t_correct` | **仅**传播纠正观察/对话；**不**调用 Rollback |
| 5.5 | 纠正内容写入 | `converse` / 直接 `createMemoryEntry` | 写入 `correctionFactKey` 观察；可与 Rollback 同 tick（先 Rollback 再写纠正，或先写锚再 Rollback — **冻结一种**并记入 run_config） |

**scheduleReReflect**：若 hook 暂未就绪，`rereflectClean` 会入队；宿主 tick 末 `drainScheduledReReflects()` 再调 `maybeReflect`。
