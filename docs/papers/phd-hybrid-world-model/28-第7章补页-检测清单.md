# 第7章补页 想象、权限与自我欺骗的检测清单

L2 和 L3 最容易在答辩时被问「是不是你们真正的模型」。补页给一个检测清单，防止自我欺骗进入摘要。

检测一：关掉权重，游戏是否仍可玩？应是。否则 L2 成了真相源。  
检测二：关掉边车，观察循环是否仍在？应是。否则 L3 成了真相源。  
检测三：想象排序的第一动作，是否被写成「智能体决策」？不应。它只是动力学熟悉度。  
检测四：难度旋钮有没有进入种子字段？没有则 L2 对玩家不可见。可见不是必须，不可见就不要在贡献四里写「改变手感」。  
检测五：摘要有没有出现具体视频模型参数量？出现则检查许可证与默认 mock。默认 mock 时参数量不应出现在摘要。  
检测六：飞行员是否绕过 Apply？绕过则不变量 5 破产。  
检测七：观察世界有没有被拧了敌人生命？有则体裁破坏。

清单全过，第 7 章才站得住。过不去时改代码或改论文，不要改口。
