# 下卷 讨论：威胁、伦理、可复现与何谓「够博士」

下卷把第 9、10 章里来不及展开的讨论写开。它仍然不提供假表。

## X.1 三种威胁如何组合出现

单独的幻觉像用错地名。单独的不可玩像走不进门。单独的塌模板像旗袍还魂。组合才是真实事故。最常见的组合是幻觉加塌模板：模型不会写船，于是交旗袍，质检若只看「能不能玩」，旗袍能玩，事故被放行。第二种组合是不可玩加精美 L3：影片很美，格子不通，用户指责智能体笨。第三种组合是日子假活加合同正确：门牌对了，所有人克隆日程，传播指标靠关键词晚会虚高。百科 N.15 和多样性门禁就是为了拆开第三种。门禁要成套，因为威胁成套。

## X.2 可复现的三个层次

层次一：同一规约同一编译器得到同一皮肤。已有测试。  
层次二：同一规约同一种子同一预算得到同一社会轨迹。原则上可，实践上若模型温度非零则否。无模型轨迹应可复现。有模型轨迹应记录模型名、温度、提示哈希。现在记录不完整，是局限。  
层次三：同一提示得到同一规约。做不到，也不该要求。模型起草有随机。可要求的是同一提示在禁名意义上同类。同类用合同检查，不用字节检查。把层次三误写成层次一，会逼人关掉模型只留启发式。启发式可复现，但会让稿件看起来像「我们其实不用人工智能」。诚实的说法：结构可复现，合同可检查，文笔不可字节复现。

## X.3 伦理再展开

居民不是人。给观察者问卷时，指导语应写「请评价模拟是否像过日子」，不要写「请评价这些居民是否幸福」。幸福是伦理越界。耳语功能应默认记录操作者。若未来接入真实社交网络数据去校准传播，必须伦理审查，本稿实现不包含这条数据通路，也不应暗示包含。视频权重非商用许可证必须出现在任何带影片的演示页脚。生成受版权保护的影视世界观时，合成器不是洗白机。论文案例用货船、渔村、修道院，避免用未授权的现成 IP 当主案例。OpenGame 游戏轨演示里出现过流行 IP 风格提示，世界栈论文不应把那些提示当科学案例。

降级伦理：用户若以为每句对话都经过深度思考，而实际是模板拷贝，应在界面标明「简略交谈」。标明不是削弱魔法，是避免把统计扩散包装成灵魂。本文测试里「不铸造假台词」是同一伦理的代码形式。

## X.4 何谓够博士

够不够由学校和评委决定。方法上，本稿提供了：明确问题、威胁模型、形式对象、可指到文件的四条贡献、继承与增量的分界、可证伪的待补实验。缺对照表和人类评测。缺的部分写在待补，不写在摘要当已有。若评委认为系统论文必须有表，应先做实验 1 和 2 再答辩，而不是在本章补假表。假表会让四条贡献一起不可信。可信比厚更重要。厚可以通过补页达到。可信只能通过不撒谎达到。

## X.5 开源与论文的互相约束

论文约束开源：不得在默认路径撒谎、不得让 L3 写任务、不得去掉禁名。开源约束论文：论文声称必须能在仓库找到。找不到的声称应删。两者互相约束，比「论文画一张架构图、代码另做一套」更接近可检验科学。读者若发现论文与代码冲突，以代码为准并开 issue，这是开源论文应有的态度。

## X.6 下卷结束

讨论不是把局限说成特色。EMA 弱就是弱。正则浅就是浅。没用户就是没用户。弱、浅、没有，仍然允许系统贡献存在。存在的方式是：失败可点名，责任可分科，皮肤可缺席，账本可对。
