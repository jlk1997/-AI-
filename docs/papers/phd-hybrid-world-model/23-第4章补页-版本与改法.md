# 第4章补页 规约演进、版本与「法律如何改法」

法律不能永远无聊而不改。游戏会要新效果，社会会要新物体状态。改法必须像改协议：版本号、迁移、旧世界仍能模拟。`dslVersion` 与规约 `meta.version` 不是同一件事。前者是语言版本，后者是这一座世界被改建了几次。语言版本变更可以加字段，不能默默删字段。删字段走主版本。世界版本变更走算子。两者都留下痕迹，调试时才知道是语言升级弄坏了旧存档，还是某次加人弄坏了连通。

旧存档迁移应写纯函数：读入旧 JSON，写出新 JSON，可测。用模型做迁移会把存档变成不可复现的文学。不可复现的存档使谱系失去意义。

关闭效果集合的压力会越来越大。有人会要求「播放动画」当效果。动画是 L3。正确写法是效果 `emit` 一个事件，呈现去播。有人会要求「让模型决定效果」。那是把法律再变成座谈会。可以在飞行员里提议效果，仍须落地成已认识的效果种类。认识是封闭的别名。

本补页强调：SSOT 不是拒绝进化，是拒绝无版本进化。无版本进化与暗改工作区是同一类罪。
