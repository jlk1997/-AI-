# 第3章补页 符号怎么用、怎么不用

形式化的误用是把定义堆成墙，墙后没有失败。第 3 章的符号只在下列时候有用：写 \(W \models I(p)\) 时能指出哪一条承诺失败；写 \(\mathrm{Apply}\) 时能指出失败不变；写 \(\mathrm{Step}\) 时能指出两个时钟；写 \(\mathrm{Compile}\) 时能指出确定性；写不变量时能指出哪一层越权。

不用符号的时候：描写 ASCII 土气、描写用户骂模板、描写定住等待。那些用大白话更准。符号和大白话抢同一句话时，留大白话，把符号放括号里。博士稿不是符号越多越像数学。数学在于承诺满足是谓词，不是在于希腊字母数量。

货船例子应成为贯穿符号的探针。每引入一个算子，问它会不会把 \(F\) 里的禁名放进来。每引入一个社会参数，问它会不会让 \(n=8\) 在编辑后变成 25。每引入 L3，问它会不会改 \(\mathcal{N}\) 里的任务状态。探针比新定义重要。
