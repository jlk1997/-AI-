# 第8章补页 工序时间线与责任人

把一次成功的世界生成想成医院接诊。分诊是模式开关：游戏轨还是世界轨。挂号是入队。问诊是意图抽出。初诊是规划起草。化验是结构校验。会诊是承诺门禁。手术是深度填充与修复。影像是资产与 L3。出院是构建与预览。随访是心跳与编辑。

责任人不是职位，是模块。抽出失败找 intent。起草失败找 planner 来源标记。校验失败找 schema。承诺失败找 synthesize 与门禁。修复失败找提示是否包含失败列表。资产失败找诚实探测。构建失败找脚手架。心跳失败找租约、锁、预算。编辑失败找 understood。责任人清晰，才不会所有病都开「再生成一次」这副药。

时间线上有两个不可交换的早检查：结构和承诺必须在影像之前。医院不会先整容再验血。整容先做的世界，就是精美的错误地图。用户会爱上错误，然后拒绝验血。门禁顺序也是产品心理学。
