# 第9章 验证、案例与待补实验

## 9.1 大白话导读：能写进论文的数字，必须能指回仓库

本章不报告虚构的人类被试平均分，不报告「在 150 个世界提示上达到新的 SOTA」。那类句子属于另一篇已发表的游戏代码智能体论文，或者属于尚未进行的实验。本章能诚实写下的只有三类证据：

1. **实现常量**：门禁和算法里写死的阈值。它们不是测量结果，是设计选择。必须标明。  
2. **自动化测试**：仓库里已经用用例钉住的行为。它们证明「至少在这些输入上，合同成立」。  
3. **定性走查**：按体裁把生成物说清楚，指出仍能看见的缺陷。

若答辩委员问「你的方法比 Park 好多少个百分点」，正确答案是：还没有在同一实验协议下做过对照，不能编。

## 9.3 自动化测试作为行为证据

测试名称本身就是主张。下面按贡献点归类，不夸大覆盖率。未列出的行为等于尚未被钉住。

### 9.3.1 规约与编译

规约测试断言：空镇合法；社会镇有广场道路与森林/客栈布局；社会镇作为村庄应有足够居民与区域（用例写明十二人以上、六区域以上的量级，并要求职业身份可区分，否则日程会塌成同一天）；子区域与家/工作的「位于」关系存在；船员英文世界给铺位和岗位盖章；布局矩形、内部可走、有门；门成对双向；未知起始区域被拒绝；JSON 往返；体裁包可往返；时钟格式区分日周期与值班；集会文案和涌现阈值跟包走，不跟「广场」走。

种子编译测试断言：地牢世界能编成合法游戏描述；**同一规约两次编译字节级相同**；区域、实体、任务、规则标识在 DSL 中可达；玩家存在且实体落在画布内；传送门接到真实场景切换；物品能形成收集获胜；敌人带追击与接触伤害从而使 L2 生命旋钮有意义；只发出运行时认识的行为；有对白的居民带对话行为。

这些测试直接支撑贡献一和贡献四的「可校验、可编译、可复现」。它们不支撑「更好玩」。

### 9.3.2 承诺约束合成

规划器测试断言：无密钥时回落启发式；普通小镇提示默认社会，不生成矿石/野狼任务；庙宇提示编译出庙宇和香案而不是无名广场；填充居民使用可区分的中文身份；每个区域补上子区域和物体；地牢原型从地牢起始而不是城镇矿石任务；编辑算子能扩展森林且不是弱置标志；实质性但未理解的编辑被拒绝；社会系统提示跟随用户语言；空间站船员包不含 `home_row`；明示人数不被灌到二十五；渔村合成不含 `town_square`；「不要塌回无名广场」不被视为经典小镇请求；经典小镇提示保留斯坦福脚手架；无效的模型叠加仍合成且不含脚手架标识；英文渔村同样不含 `town_square`；夜市提示不泄漏茶馆地名。

这组测试是贡献二最硬的证据。它们证明合同在仓库的回归集上可执行，尤其是反塌缩。它们仍不是大规模提示词基准。

### 9.3.3 社会内核

智能体测试覆盖：关键词检索；下落处加成（中英）；计划地点盖上可读名称；社会小时推进发出事件；重要性到达则反思；对话扩散高重要性谣言；A\* 绕墙；**在两个模拟日内信息扩散达到至少百分之三十**（注意：这是短窗口测试阈值，不是体裁包的百分之七十）；人不会在目标格子上冻住；持久姿态与记忆可叠到规约种子上；空的持久关系不擦掉种子关系；从对话事件重建说话冷却；耳语记忆清除冷却；没有模型且没人有新闻时跳过口头节拍；两人谈话传播耳语观察；解析带思考标签的 JSON；修复截断 JSON；说话时定住走路者；白天聚集不误盖饥饿、并在短时间内冷却；模型返回空或仅思考时不伪造模板台词；新鲜谣言即使在夜里也倾向交谈；优先找记得的邻居而不是最近的陌生人；调查附近熄灭的炉子；工作时间向同事靠拢；谣言能在一步内把分散的人拉到广场交谈；旁观者并进同一圈；**模型预算耗尽时仍进行降级交谈**；职业得到跨区域的不同日程；昨日反思影响次日职业计划；小时块分解成具体动作而不是「第几步」；英文职业计划分解成英文节拍；驱动能打断日程并重规划；锚点落在可走格而不在墙里。

请注意「百分之三十 / 两日」与「百分之七十 / 一日」同时存在。前者是单元测试为了在无模型、短时间、低成本下仍然失败得了而设的松阈值；后者是产品体裁门禁。不得把百分之三十写成本文的科学发现，也不得把百分之七十写成已经在每次持续集成中对模型对话实测达到。正确表述：传播逻辑被测试钉住；产品阈值被代码定义；完整门禁评测函数存在，可在给定小时数下跑。

### 9.3.4 其它包

世界算子、模拟器、神经混合、占用模型、质量门禁各有测试文件。流水线有诚实性测试，防止失败被报成成功。本文不把「有测试文件」说成「已发表实验」。有测试意味着主张可被仓库证伪。这已经比许多系统论文只给截图要强，但仍弱于对照实验。

## 9.4 定性案例（应在答辩时现场打开系统）

**案例 A：经典小镇。** 提示明确点名斯坦福式广场。允许脚手架标识。居民十八名量级，傍晚枢纽在广场。适合复现生成式智能体式观察。风险：用户若只说「小镇」而没点名，不应走到这条路。测试已覆盖「不要塌回」的否定。

**案例 B：运河货船 / 空间站船员。** 体裁为值班，枢纽为舰桥，禁 `home_row`，人数可明示为六到十四。文案应是交班不是晚会。风险：填充日程若仍写「去广场」，即制度文案回归。已有测试要求船甲板枢纽改写填充日程。

**案例 C：修道院。** 日课与食堂/礼拜堂。人口介于镇与船之间。风险：模型起草仍塞战斗任务。社会优先默认与门禁的零任务要求用于挡住。

**案例 D：渔村 / 庙宇 / 夜市。** 合成必须出现用户地点，不得用码头一带一类空泛标签冒充，不得串味到茶馆。测试已点名这些失败模式，说明它们在开发中真实出现过。论文把「出现过的失败变成测试」视为工程质量，而不是视为已经消灭该类失败。

**案例 E：角色扮演取矿。** 仅当提示要胜负或战斗循环。此时深度填充补任务与敌人，L2 旋钮才有意义。风险：默认泄漏进观察世界。规划器测试断言普通镇提示不含矿石野狼。

定性案例不能替代用户研究。它们说明管道在作者关心的几个原型上可走通。

## 9.5 威胁模型对照：我们实际挡住了什么

幻觉：禁名、地点覆盖、职业覆盖、无效模型叠加仍合成。仍可能发生的幻觉：覆盖函数的假阳性/假阴性、模型在合法标识下写错制度细节。

不可玩：布局可走测试、编译可达测试、A\* 绕墙、人不冻在目标上、L3 真实图探测。仍可能发生：构建环境差异、外部资产接口失败、长会话中的状态漂移。

塌模板：大量合成测试针对 `town_square` / `home_row` / 无名广场。仍可能发生：新脚手架被加入后禁表未更新——这是维护风险，应用「禁表与脚手架标识同源」来缓解。

降级传播：预算耗尽仍交谈、无新闻则不伪造台词。仍可能发生：模板扩散过弱，导致产品阈值百分之七十在无模型时达不到。这不是测试造假，这是需要报告的局限：单元测试采用百分之三十，说明作者知道无模型短跑达不到产品阈值。

## 9.6 待补实验清单（做完之前不得写入结论）

**实验 1：体裁门禁达标率。** 固定种子集合，含镇、船、修道院、渔村、夜市、角色扮演。记录承诺门禁一次通过率、修复后通过率、来源标记分布。报告中位数区域数与人数。

**实验 2：涌现对照。** 条件包括：无模型模板、有模型对话、关闭占用惊讶、关闭需求打断、关闭信念。指标用评测卡全套。协议固定二十四小时、步长 0.25、种子若干。这才能回答占用模型是否改变可观察行为。

**实验 3：与固定 Smallville 的对照。** 在经典小镇提示下，比较信息扩散曲线是否接近 Park 报告的观察（不是要求数字相同，要求曲线形状可讨论）。必须公开降级条件，否则模型差异会淹没方法差异。

**实验 4：观察者研究。** 让人看回放，问「像不像过日子」「像不像用户要的那个地方」。预先注册评分表。样本量写进计划，不得事后只报告好看的子集。

**实验 5：编译可玩性。** 对角色扮演子集跑无头探针和构建成功率。与游戏代码智能体轨道对比时，必须说明任务不同，不能直接比「谁 SOTA」。

**实验 6：L3 可缺席性。** 关闭边车，断言观察循环仍完整。打开模拟帧，断言任务状态不变。这是不变量 1 的实验形式。

在这些实验完成前，本文的评价句只应是：**系统可运行、合同可测试、关键失败模式已被回归钉住、完整科学对照尚未做。**

## 9.7 局限

启发式合成土气。EMA 不是强预测器。多层感知机不是 Dreamer。LingBot 默认常为模拟帧。正则意图抽出不是语义理解。双时钟桥接在复杂编辑后可能丢细节。社会写回规约若过大胆会破坏 SSOT。测试集由作者构造，存在确认偏误。中英之外的语言未认真支持。

这些局限不降低已落地模块的价值，它们规定了下一步。把局限藏起来，拆出去的 SCI 稿会被审稿人用同一段话打回。

## 9.8 答辩演示建议（仍不是实验数据）

建议准备三分钟无旁白也能看懂的操作。第一分钟：输入货船提示，打开规约摘要，用手指区域名，确认没有城镇广场。第二分钟：快进社会，打开某位船员记忆，指出「听同伴说」或种子文本。第三分钟：关掉电影层（若开着），再走一步，指出任务或观察循环仍在。若现场密钥失败，切换到已保存的回放，不要当场重生成碰运气。回放能演示日子，不能替代生成合同，应向委员说明你展示的是哪一条证据。

准备一张失败对照：故意输入「不要广场」却展示旧版本塌缩结果的截图（来自测试或开发日志），再展示当前禁名通过。失败对照比成功演示更能证明贡献二不是口号。

不要在演示里打开未完成的 L3 真权重。失败的影片会把讨论拖进显存，而不是拖进方法。

## 9.9 小结

证据目前是工程科学意义上的：常量可追溯，测试可证伪，案例可演示。证据还不是比较科学意义上的：没有对照表，没有人类评分，没有对外宣称的百分比胜利。下一章在这个边界内下结论，并说明若要投稿，三篇稿应分别承诺做什么实验。
