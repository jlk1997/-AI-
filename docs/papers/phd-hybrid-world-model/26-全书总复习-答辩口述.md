# 全书总复习（可当答辩口述稿）

下面按二十分钟口述的节奏把全书说完。口述可以丢公式，不能丢诚实。

开场三十秒：我们要解决的不是「人工智能会不会写游戏」，而是「一句话能不能同时变成可对账的世界、会过日子的居民、和可脱掉的皮肤」。

两分钟讲失败：代码会飘，视频不能捡矿，固定小镇不是你的船。三种失败对应幻觉、不可玩、塌模板。

三分钟讲分层：说明书是 L1，永远不被网络替换。日子在说明书上过。L2 做梦建议闹钟。L3 放宣传片。宣传片宕机后厨不停。

三分钟讲合同：愿望拆成制度、地点、职业、人数、禁名。生成器再华丽，门牌叫 town_square 就打回。填充可以补全，不可以擅自扩编。编辑继续执行合同。

四分钟讲日子：一刻钟一拍。记忆、计划、需求、寻路、对话。人流预测错了，全镇更想去看。没钱用模板传消息，没新闻就闭嘴。身体凑在一起才叫遇见。评测失败则不许假装成功。阈值是设计，不是成绩。百分之三十的测试和百分之七十的产品愿望不是同一个数。

两分钟讲皮肤：编译要确定性。观察世界不要顺手加狼。飞行员导演改许可证不改像素。

两分钟讲证据：仓库里有测试钉住渔村、空间站、否定广场、预算耗尽仍说话、编译字节一致。没有人类平均分。没有 150 提示 SOTA。那些属于邻居论文或未来实验。

一分钟讲投稿：不投 Nature。拆三稿，B 稿等对照。继承 Park，不吞并 OpenGame。

结束句：先写能对账的说明书，再一步步过日子，最后才穿衣服。衣服可换，账不能改。

若评委追问占用模型太简单：简单是为了在场。在场的傻瓜预测比不在场的天才预测更像生活里的世界模型。若关掉它什么都不变，我们会把贡献三改写，不会改口说变了。

若评委追问有没有用户：还没有。第 9 章写着。编一个分数比没有分数更糟。

若评委追问这是不是工程报告：工程报告没有否决权、在场预测、不变量和可证伪问题。本文有。缺的是对照表。对照表列在待补，不列在摘要当已完成。

口述到此。书面章节按 README 的阅读顺序装订。补页并入相应章，附录放后面。中卷细讲可放第 8 与第 9 章之间。
