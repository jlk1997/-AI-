# 隔壁 / Gebi 控制台（`@opengame/platform-web`）

玩家与作者共用的站点：**玩 → 改一句 → 再发布**。海外展示名是 Gebi。插件市场、Research Lab、自定义域名、公开 Bench 默认不上导航。

开发时先起 API（默认 `:3847`），再：

```bash
npm run dev --workspace=@opengame/platform-web
```

打开 `http://127.0.0.1:5174`。产凭镜像与边缘配置见仓库根目录 `deploy/` 与 `docs/platform/hosted-deployment.md`。
